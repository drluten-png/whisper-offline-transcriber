# Whisper — офлайн-транскрибация аудио и видео (v2.3)

Локальное приложение: перетаскиваете аудио/видео любого формата — получаете
текстовую расшифровку. Работает **полностью офлайн**.

По умолчанию стоит **сжатая модель `whisper-large-v3-turbo-q4`** (442 МБ вместо
1611 МБ): на реальном 10-минутном фрагменте она заняла **801 МБ памяти против
1334 МБ** у полной версии и оказалась на 10% быстрее — при сопоставимом качестве.
В кеше хранятся только квантованные модели.

Оптимизировано под **слабые машины (8 ГБ памяти)**: звук обрабатывается кусками,
куски удаляются сразу, память не растёт, зависшая задача не блокирует очередь.

## Установка (если вы склонировали репозиторий)

Нужен Mac с процессором **Apple Silicon (M1–M4)** — приложение использует MLX,
на Intel и Windows оно не работает. Также нужен [Homebrew](https://brew.sh).

В Terminal, в папке приложения:

```bash
brew install ffmpeg
bash setup.sh
```

`setup.sh` создаст окружение `.venv`, поставит библиотеки и **один раз** скачает
модель распознавания (~450 МБ). Дальше интернет не нужен.

## Как запустить

1. Откройте папку `whisper_app`.
2. Дважды кликните **`Запустить Whisper.command`**.
3. Откроется окно Terminal (его не закрывайте — это и есть приложение) и
   автоматически откроется браузер.
4. Перетащите файлы в окно браузера. Готовые `.txt` появятся в
   `whisper_app/output/`.

Чтобы выключить — закройте окно Terminal.

> Первый запуск macOS может показать предупреждение о неизвестном разработчике.
> Тогда: правый клик по `Запустить Whisper.command` → «Открыть» → «Открыть».
> Если файл не кликается, выполните один раз:
> `chmod +x "whisper_app/Запустить Whisper.command"`

## Словарь терминов и имён

Самая частая беда распознавания — имена и специальные слова: «гигель» вместо
**Гегель**, «фацилитатор» вместо **фасилитатор**.

Словарь исправляет это сам:

- **Правильные слова** из словаря уходят в подсказку распознаванию — модель чаще
  пишет их верно сразу.
- **Замены** правят уже готовый текст. Указывается *основа* слова, поэтому правило
  «гигел → Гегел» исправит и «Гигелем», и «Гигеля». Регистр сохраняется: с маленькой
  буквы останется с маленькой.

Где править: в панели приложения, блок **«Словарь терминов и имён»**. Формат —
одна запись в строке:

```
# просто слова — как правильно (идут в подсказку)
Гегель
фасилитатор
экспедиция

# замены: как слышится → как правильно (основа слова)
гигел → Гегел
фацилитатор → фасилитатор
ликтофон → диктофон
```

Кнопка **«Словарь»** у готового файла применяет замены к уже созданному
транскрипту (оригинал на всякий случай сохраняется в `data/backup/`).

На тестовой записи это убрало **7 ошибок**, после чего неправильных слов не осталось.

## Новое в v2.2

- **Деление по паузам (Silero VAD).** Запись анализируется маленькой моделью
  распознавания речи (2 МБ, считается на процессоре), и куски режутся **по тишине**,
  а не по 10-й минуте. Это убирает обрывы слов и дубли на стыках.
  Поиск пауз по 51-минутной записи занимает **4 секунды**.
- **Пропуск тишины.** Куски, где нет речи (пауза, выключенный микрофон, музыка),
  вообще не отправляются в распознавание — меньше выдуманного текста и быстрее.
  Если VAD недоступен, приложение работает как раньше (по громкости).
- **Переименование готовых файлов.** Кнопка «Переименовать» прямо в списке:
  Enter — сохранить, Escape — отменить. Имя переживает перезапуск приложения.
- **Понятное скачивание.** Если приложение закрыто, вместо страницы с ошибкой
  браузера появляется сообщение и подсказка, где лежит файл.

## Выбор модели

Модель переключается прямо в приложении — в панели есть список «Модель распознавания».
Показано, какие модели уже скачаны, а какие можно докачать.

В проекте используются **только квантованные (сжатые) модели** — они занимают
в разы меньше места и памяти при том же качестве. Полная версия (1611 МБ) удалена,
чтобы не занимать диск.

| Модель | Размер | Память (замерено) | Когда выбирать |
|---|---|---|---|
| **Large v3 turbo, сжатая (4 бита)** — стоит по умолчанию | 442 МБ | ~800 МБ | Обычный режим: проверено на реальной записи |
| Medium, сжатая (4 бита) | 489 МБ | ~1 ГБ | Слабее и медленнее turbo — брать смысла мало |
| Small, сжатая (4 бита) | 187 МБ | ~600 МБ | Только если памяти совсем нет: заметно хуже имена и термины |

Важно: `turbo` — это ускоренный вариант `large-v3` (в 8 раз быстрее). Модели
`medium` и `small` — другие, более старые: они меньше, но для русского **хуже и
медленнее**. Поэтому уменьшать размер имеет смысл сжатием (q4), а не сменой модели.

Замеры сжатой модели на реальном 10-минутном фрагменте: **801 МБ памяти, 58 секунд**
(полная версия для сравнения: 1334 МБ и 64 секунды).

Скачивание модели — **разовое действие и требует интернета**. Всё остальное время
приложение работает офлайн и в сеть не ходит.

## Что нового в v2.0 (исправлено по итогам полного аудита)

**Качество распознавания живой речи**
- **Пропуск тишины.** Куски без речи (паузы, выключенный микрофон) больше не
  уходят в распознавание — меньше выдуманного текста и быстрее обработка.
- **Фильтр галлюцинаций.** Убираются классические фразы-призраки
  («Продолжение следует…», «Субтитры сделал…» и подобные), которые Whisper
  сочиняет на шуме, музыке и тишине.
- **Стыки кусков больше не рвут слова.** Куски теперь берутся с перекрытием
  15 секунд, лишнее отсекается по времени — нет дублей и обрезанных слов.

**Любые форматы и дорожки**
- **Несколько звуковых дорожек.** Если первая дорожка пустая или тихая,
  приложение автоматически берёт следующую (частая ситуация в записях OBS и камер).
- **Понятные русские ошибки:** «в файле нет звуковой дорожки», «файл повреждён»,
  «нет места на диске», «не найден ffmpeg» — вместо английского текста ffmpeg.

**Надёжность**
- **Результат сохраняется целиком или никак:** недописанный файл больше не
  может выглядеть как готовый.
- **Задачи переживают перезапуск:** журнал сохраняется, прерванную задачу видно
  и можно нажать «Повторить».
- **Зависшая задача не блокирует очередь:** есть сторож по времени.
- **Не копятся временные файлы:** куски удаляются сразу после распознавания.

**Интерфейс**
- **Предупреждение о потере связи:** если окно Terminal закрыто, вы увидите баннер,
  а не замерший экран.
- **Видна вся очередь загрузок**, есть «Отменить», «Убрать», «Повторить».
- **Защита от потери долгой загрузки:** браузер предупредит перед закрытием страницы.
- **Папки не принимаются за файлы** — появляется понятная подсказка.
- **Перетаскивать можно в любое место окна**, не только в пунктирную зону.
- **Индикатор свободной памяти**; при нехватке — жёлтое предупреждение.
- **Оценка времени** («осталось ~N мин») и подробности ошибок по кнопке.

## Возможности

- Форматы: `mp3, wav, m4a, m4b, aac, flac, ogg, opus, wma, amr, aiff, caf,
  mp4, mov, mkv, webm, avi, wmv, mpg, ts, 3gp` — и вообще всё, что читает ffmpeg.
  Тип определяется по содержимому, а не по расширению.
- Несколько файлов сразу — обрабатываются по очереди.
- Результат не перезаписывается: повторный файл сохранится как `имя (2).txt`.
- Подсказка для терминов и имён (до 500 символов) повышает точность.
- Кнопки «Открыть папку результатов» и «Показать в Finder».

## Настройки (необязательно)

Задаются переменными окружения перед запуском:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `WHISPER_MODEL` | (выбранная в интерфейсе) | принудительно задать модель при запуске |
| `WHISPER_LANGUAGE` | `ru` | язык распознавания |
| `WHISPER_CHUNK` | `600` | размер куска в секундах (минимум 60) |
| `WHISPER_OVERLAP` | `15` | перекрытие кусков в секундах |
| `WHISPER_MIN_CHUNK` | `120` | минимальная длина куска |
| `WHISPER_VAD` | `1` | `0` — выключить определение речи по VAD |
| `WHISPER_VAD_THRESHOLD` | `0.5` | порог вероятности речи |
| `WHISPER_VAD_SNAP_WINDOW` | `90` | на сколько секунд можно сдвинуть границу куска к паузе |
| `WHISPER_SILENCE_DBFS` | `-65` | порог тишины по среднему уровню |
| `WHISPER_SILENCE_PEAK_DBFS` | `-45` | порог тишины по пикам |
| `WHISPER_STALL_SECONDS` | `2700` | через сколько считать задачу зависшей |
| `WHISPER_MAX_UPLOAD_GB` | `64` | максимальный размер файла |
| `WHISPER_NO_BROWSER` | — | `1` — не открывать браузер |
| `WHISPER_ALLOW_NET` | — | `1` — разрешить докачку модели из интернета |

## Если что-то не работает

- **«mlx_whisper недоступен»** — запуск не через `_venv`. Проверьте, что папка
  `_venv` лежит рядом с `whisper_app` (то есть в родительской папке).
- **«Не найден ffmpeg»** — установите: `brew install ffmpeg`.
- **Модель не найдена** — она должна быть в кеше HuggingFace
  (`~/.cache/huggingface/hub`). Без интернета докачка невозможна.
- **Мало памяти** — закройте лишние вкладки браузера и программы. Модель занимает
  около 1.6 ГБ, пик обработки — около 2 ГБ.
- **Жёлтый значок памяти** — свободной памяти меньше 2.5 ГБ; обработка возможна,
  но будет идти медленнее (система уйдёт в своп).
- **Порт занят** — приложение само выберет свободный (8765 и далее).
- **Второй запуск** — если приложение уже работает, повторный клик просто откроет
  его окно, второй экземпляр не запустится.
